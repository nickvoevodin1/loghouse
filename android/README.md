# ЛогХаус для Android

Тонкая оболочка вокруг календаря плюс настоящий виджет на домашний экран.

## Что внутри

- `MainActivity` — WebView с календарём. Страница лежит внутри apk
  (`assets/index.html`), поэтому приложение открывается без интернета.
- `WidgetProvider` / `WidgetService` — виджет: дата, кнопка «+» и
  прокручиваемый список событий на сегодня.
- `EventStore` — события в `SharedPreferences`. Их кладёт туда сам календарь
  через JS-мост `LogHouseWidget` при каждом сохранении, так что виджету
  не нужны ни сеть, ни сервер.

## Что умеет виджет

- список событий на сегодня, прокручивается;
- цветная полоска календаря у каждого события;
- тап по событию — открывает его в приложении;
- тап по «+» — открывает создание события;
- тап по дате — открывает день;
- у задач есть галочка, она отмечается **прямо в виджете**, без открытия
  приложения; отметка доезжает до календаря при следующем запуске.

Двигать события внутри виджета нельзя — Android этого не позволяет ни одному
приложению, включая Google Календарь.

## Сборка

APK собирается на GitHub Actions при каждом пуше в `main`
(вкладка Actions → Android APK → артефакт `loghouse-apk`).

Локально, если стоит Android SDK:

    cp index.html android/app/src/main/assets/index.html
    cd android && gradle assembleRelease

## Установка

APK подписан отладочным ключом — магазин не нужен. На телефоне разрешить
установку из этого источника и открыть файл. Затем долгий тап по домашнему
экрану → «Виджеты» → ЛогХаус.
